# Snake Game 🐍

A simple Snake Game developed with Python.

## About the Project

This project is a classic Snake Game where the player controls a snake, collects food, and tries to achieve a higher score without hitting the walls or its own body.

## Features

- Snake movement controls
- Food collection
- Score tracking
- Collision detection
- Game over condition

## Technologies Used

- Python

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder.
4. Run the main Python file:

```bash
python main.py
```

**Note:** If the project uses additional libraries, install them before running the game.
